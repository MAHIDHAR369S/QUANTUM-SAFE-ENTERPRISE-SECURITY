# QuantumSafe Complete Frontend

Next.js + React + TypeScript + Tailwind frontend MVP.

## Functional flows
- Dashboard and navigation
- Security Scan modal, progress simulation, results, and dashboard state update
- Asset search/filter/detail modal
- Risk filtering
- Migration status updates
- AI Copilot mock chat
- PQC Lab interactive demo
- Compliance checklist and JSON report download
- Notifications and profile menus
- Latest scan persisted in localStorage

## Run
```bash
npm install
npm run dev
```
Then open http://localhost:3000

The scanner, Copilot, and PQC lab are demo simulations until connected to a backend.
